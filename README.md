# Larry Math

Ein kleines Lernspiel im Stil von Larry Boardgame.

## Start

```bash
node server.js
```

Dann im Browser öffnen:

```text
http://127.0.0.1:4173
```

## Spielidee

Eine alte Lehrerin stellt an der Tafel fünf einfache Additionsaufgaben im Zahlenraum bis 10. Nach jeder Antwort gibt es direkt Rückmeldung. Am Ende zeigt das Spiel richtige und falsche Antworten sowie Bonuspunkte für schnelle Antworten.
